JARVIS 2.0

A private, owner-operated assistant that runs on the owner's Windows computer.

JARVIS uses local language and speech models to help its owner inspect information and carry out authorized tasks. Connected Google accounts allow work with email, calendars, files and contacts. Google services still process the API requests sent to them.

Account access is granted through Google's consent flow. JARVIS stores Google authorization credentials locally using Windows user encryption. Its authority controls govern actions. Local conversations, action records and Obsidian notes may retain information used in a task.

This is a private installation, not a public hosted assistant or an invitation to connect other people's accounts. Support is provided by the owner who operates the installation.
